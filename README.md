# PiPlot

### Raspberry Pi Real-Time Sensor Data Visualization

PiPlot is a Raspberry Pi-based application developed to visualize sensor readings in a web browser.

The project was originally created as a student software assignment and is preserved here as part of my software development portfolio.

## Overview

The application combines a Java-based backend with a web interface to display sensor measurements.

## Technologies

- Java
- Spring Boot
- Maven
- JavaScript
- Raspberry Pi
- Pi4J

## Project Goals

- Acquire measurements from a Raspberry Pi-connected sensor
- Transfer measurement data to a backend application
- Visualize the incoming data through a browser-based interface

## Project Status

**Legacy / Educational Project**

This application was developed several years ago. Its dependencies and compatibility with current hardware and Java versions have not yet been revalidated.
